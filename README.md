## Features
- **Real-time Data**: Fetched directly from Yahoo Finance.
- **AI Predictions**: Custom weighted ensemble engine based on technical indicators.
- **Interactive Charts**: visualized with Recharts and Tailwind CSS.
- **Watchlist**: Track your favorite stocks.
- **Accuracy Tracking**: AI evaluates its own past predictions.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, Recharts.
- **Backend**: Node.js, Express, SQLite (sql.js).
- **Deployment**: Vercel (Serverless Functions).
